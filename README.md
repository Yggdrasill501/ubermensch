# Übermensch

An AI coworker you hire, not prompt. It interviews you in Slack about its role, then works 24/7 across
Slack, Linear and GitHub: it picks up work on its own, runs parallel agents, and asks when stuck.

- Plan and architecture: [PLAN.md](PLAN.md)
- Setup: [SETUP.md](SETUP.md)
- Quick start: `nvm use && npm install && cp .env.example .env && npm run dev`
